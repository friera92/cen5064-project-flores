# ADR-003: Implement a Reservation State Machine

**Date:** 2026-08-31
**Status:** accepted

## Context

Reservations follow a defined lifecycle, requiring controlled transitions to prevent invalid operations and maintain consistency.

## Decision

Implement a state machine with the following reservation states: REQUESTED, APPROVED, ACTIVE, RETURNED, CLOSED, CANCELED, and DISPUTED. State transitions are enforced by the Reservation Service.

## Consequences

This ensures consistent reservation workflows and prevents invalid state changes. However, adding new states or transitions requires updating the business rules.
