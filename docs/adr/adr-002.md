# ADR-002: Adopt Repository and Service Layer Patterns

**Date:** 2026-09-14  
**Status:** accepted

## Context

NeighbourLend requires consistent business rules and database operations across multiple features, including users, tools, and reservations.

## Decision

Use the Repository Pattern to encapsulate data access and the Service Layer Pattern to manage business logic and application workflows.

## Consequences

This approach improves separation of concerns, maintainability, and testability. However, it introduces additional classes and interfaces.
